# 0013. Apache-2.0, a README, and an app icon drawn in code

- Status: accepted
- Date: 2026-11-27

## Context and problem

**Why now.** The repository went public on 2026-11-26 with no licence, so nobody had permission to
use its code. Every published build embeds Sparkle, whose licence requires its notice to travel
with it, and a release disk image showed a blank icon. All of it was to be fixed.

**The icon** is drawn in code rather than in a design tool, so a cloud session can regenerate it.
It is a cream legal pad on a sage tile, with a terracotta binding strip, ruled lines and a Markdown
heading mark (#) in the margin. It was chosen from five drawn candidates. It
replaced the first icon, the public-domain Markdown mark on a paper page. That one said "Markdown
document" where the app is a notes-style editor. The pad is busy at Finder-list sizes, so 16 and
32 px get simpler art: the pad, the strip and four heavier rules.

## Decision drivers

**Criteria.**

1. The maintainer's precedent across their projects.
2. vision.md's "no lock-in".
3. Clear permission for anyone who finds the code.
4. Cost.

## Considered options

**The licence.**

| Option | 1 | 2–3 | 4 |
| --- | --- | --- | --- |
| **Apache-2.0 (chosen)** | ✓ latchkey, the maintainer's other public app with a licence | ✓ permissive, with an explicit patent grant | ✓ |
| MIT | ✗ not used by the maintainer | ✓ but no patent grant | ✓ |
| GPL-3.0 | ✗ | ✗ copyleft limits reuse | ✓ |
| None (Otos's choice) | ~ | ✗ all rights reserved, so the public code cannot be used | ✓ |

## Decision

**Decision.** The repository is licensed under the Apache License 2.0. It has a README for people
who find it, and an app icon generated by `Scripts/make-app-icon.py`. Sparkle's MIT notice now ships
in the app beside cmark-gfm's.

## Consequences

**Where it is worse.** A licence is the maintainer's to choose, and this one was chosen for them, by
precedent. Code published under Apache-2.0 stays available under it. While the app has no users,
switching to another licence for later versions costs one commit.

## Confirmation

`LICENSE` is Apache-2.0; the app bundles `Markdown Editor/Licenses/Sparkle-LICENSE.txt` and `cmark-gfm-COPYING.txt`; the icon is regenerated by `Scripts/make-app-icon.py`.

## Retirement proof

A contributor or distribution channel needing a different licence.

## Reversal plan

Relicense later versions in one commit; published code stays available under Apache-2.0.
