# Docs

- [Requirements](requirements.md): what the app does today, each requirement with its tests.
- [Architecture](architecture.md): how it is built — drivers, state ownership, runtime contracts,
  and the `ARC-###` invariants with their proofs.
- [Decisions](adr/): one ADR per decision that shapes the code, superseded ones kept
  ([template](adr/0000-template.md)).
- [Lessons](lessons.md): rules learned the hard way, and problems still open.
- [Vision](vision.md): product direction, the objective ordering decisions are ranked by, and how
  the product is evaluated.
- [Roadmap](roadmap.md): what was delivered, in sequence; open work is in GitHub issues.
- [Development](development.md): environments, CI, releases, the one-time setup, and how to plan an
  increment.
- [Research](research/README.md): dated evidence (`YYYY-MM-DD-topic.md`), never architecture
  authority.
- [Screenshots](screenshots/README.md): the committed gallery of the product's screens.
