# The tour: the whole app, used the way a person uses it on a Mac, from a plain launch to a
# relaunch. `.github/workflows/agent-drive.yml` runs it with Scripts/agent-drive.swift, which
# lists the steps. Each section says what a person would be doing; screenshots and trees are for
# the agent's eyes, `expect` steps for the verdict, and `expect-no-faults` asks the app's own log.
#
# $WORK holds a copy of Scripts/Fixtures. The tour writes its own notes into $WORK/notes.

shell mkdir -p "$WORK/notes" "$WORK/pictures" && cp "$WORK/assets/sample.png" "$WORK/pictures/photo.png"

# --- A. A plain launch, as from the Dock, opens an untitled document big enough to read in.
launch
expect-windows 1
expect-window Untitled
windows
shot a-launched
tree a-launched
expect-no-faults

# --- B. Writing a note from the keyboard: a heading, a paragraph, inline formatting.
type "Weekly notes"
key cmd+1
key return
type "Today I fixed the printer and wrote this note in plain Markdown."
wait 1
shot b-typed
expect-value "Markdown WYSIWYG" "Weekly notes"
expect-value "Markdown WYSIWYG" "Today I fixed the printer and wrote this note in plain Markdown."
select "Markdown WYSIWYG" printer
key cmd+b
select "Markdown WYSIWYG" "plain Markdown"
key cmd+i
select "Markdown WYSIWYG" fixed
key cmd+shift+x
select "Markdown WYSIWYG" wrote
key ctrl+cmd+c
wait 1
shot b-formatted
value "Markdown WYSIWYG"
expect-no-faults

# --- R. Quit and relaunch. With macOS's default "close windows when quitting", a plain launch opens
# an untitled document, as TextEdit does; the note comes back through File › Open Recent.

expect-not-running
launch
wait 3
windows
expect-window Untitled

wait 2
windows
